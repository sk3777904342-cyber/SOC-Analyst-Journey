## Important Ports

| Port | Protocol | Purpose |
|------|----------|---------|
| 20/21 | FTP | File Transfer |
| 22 | SSH | Secure Remote Access |
| 25 | SMTP | Email |
| 53 | DNS | Domain Name Resolution |
| 80 | HTTP | Web |
| 443 | HTTPS | Secure Web |
| 3389 | RDP | Remote Desktop |

## Subnetting

/24 = 255.255.255.0

/26 = 255.255.255.192

/26 Block Size = 64

Networks:
- 192.168.1.0/26
- 192.168.1.64/26
- 192.168.1.128/26
- 192.168.1.192/26
